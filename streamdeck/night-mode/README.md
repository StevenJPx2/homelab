# Stream Deck night mode

Blanks the Stream Deck while Home Assistant's `input_boolean.night_mode` is on. HA turns that
on 3 s after `light.bedroom_ambient` goes off and off when the light comes back on (automation
`night_mode_follows_bedroom` in [`nixos/configuration.nix`](../../nixos/configuration.nix)).

- **Night on:** the plugin switches each deck to its bundled `Night` profile, 15 black Wake keys.
- **Night off, or any key pressed:** it switches back to the previous profile.

The plugin follows the entity over HA's WebSocket API (`subscribe_entities`, which needs no
admin rights) at `http://192.168.0.40:8123`.

## Setup on a Mac

The HA long-lived token lives in the macOS Keychain, not in a file:

```sh
security add-generic-password -U -s stream-deck-night-mode -a home-assistant -T /usr/bin/security -w '<token>'
```

Build and install (Node 24+):

```sh
npm install
npm run build                                 # plugin, icon, and profiles/Night.streamDeckProfile
npx streamdeck link xyz.stjhn.night-mode.sdPlugin
```

Then quit and reopen Stream Deck so it loads the plugin. Logs:
`xyz.stjhn.night-mode.sdPlugin/logs/`.

The Night profile is generated by `scripts/build-profile.mjs` for a 15-key Stream Deck
(model `20GAA9902`).
